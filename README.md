# DCL Revenue Agent

Private revenue intelligence for Digital Commerce Lab.

## Current milestone
M0 foundation + M1 dashboard shell.

Included now:
- explainable Fit / Need / Intent / Opportunity scoring
- deterministic qualification tiers
- sales-motion selection
- account/signal/contact/proof/outreach data model
- dashboard shell and opportunity detail screen
- human-approval and evidence provenance guardrails
- automated scoring tests

## Run locally
1. Copy `.env.example` to `.env.local`.
2. `npm install`
3. `npm run dev`

## Test scoring
`npm test`

## Build sequence
M1 Discovery -> M2 Intelligence -> M3 Outreach -> M4 Learning.
